Wall text

        
Painters and programmers have always done the same work.

        
Painters sketch, mix a palette, lay down strokes, step back and paint over what isn’t working. Developers prototype, pick a theme, type, run the tests and refactor. This exhibition hangs the second group’s work the way museums hang the first: framed, lit and labelled.

The permanent collection

        
Twenty-three centuries of code, framed.

        
Six programs, from Euclid to Quake III Arena, hung in the order they were written. Each painting is generated in your browser from the source on its label, so the same code always makes the same picture.
